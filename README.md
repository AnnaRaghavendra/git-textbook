# Git: From Fundamentals to Advanced Concepts

A structured Git and GitHub textbook designed to teach version control from beginner to advanced levels through clear explanations, practical examples, and hands-on exercises.

---

## About This Book

This book was created to provide a complete learning path for Git and GitHub.

The content progresses from fundamental concepts such as repositories, commits, and branches to advanced topics including rebasing, recovery techniques, Git internals, collaboration workflows, and release management.

The goal is not only to explain Git commands, but also to develop a strong understanding of how Git works internally and how it is used in real-world software development.

---

## Intended Audience

This book is suitable for:

* Students learning Git for the first time
* Developers preparing for internships or jobs
* Open-source contributors
* Software engineers seeking a deeper understanding of Git
